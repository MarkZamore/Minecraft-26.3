# Метаданные библиотеки

Карточка продолжает стабильный ID `minecraft-26-2`; имя и `relativePath` обновлены до `Minecraft 26.3`. Это одна обновляемая сборка, а не новая независимая карточка.

`emi` указывает на [EMI Unofficial Port (Unstable)](https://www.curseforge.com/minecraft/mc-mods/emi-unofficial-port-unstable). Поставляется JAR автора этого порта, поэтому страница исходного EMI другого проекта не подставляется вместо него. Автор link-fgfgui, точные CurseForge files 8616659 → 9242955 и старый/новый SHA-256 проверены при подготовке обновления; см. [протокол](../tools/UPGRADE-26.3.md). Новый файл для Minecraft 26.3 имеет канал Alpha, как и прежний порт для 26.2.

В библиотеке указаны четыре активных mod ID: `emi`, `iris`, `sodium`, `lanmc_world_menu`. Iris и Sodium ссылаются на официальные CurseForge-страницы своих проектов. `lanmc_world_menu` помечен вспомогательным компонентом: это собственный World Menu Policy, существующий внутри данной сборки. Самостоятельной страницы CurseForge/Modrinth у него нет; официальный источник, описание и поставка находятся в этом репозитории. Его ссылка не подменяется страницей одноимённого чужого мода.

e4steam устанавливается общим лаунчером отдельно и не дублируется в этом репозитории. Исторический EMI из `legacyFiles` не попадает в библиотеку и активные downloads.

`tools/pack_library.py` читает имена и версии из реальных JAR, требует проверенные HTTPS-страницы, собирает детерминированный `library-<sha256>.zip` и записывает `websiteUrl`. Наблюдение предыдущего состава с Iris/Sodium хранится отдельно в `tools/shader-support-runtime.json`. Оно не подтверждает запуск нового компонента World Menu Policy: для него выполняются компиляция, нативные JVM-проверки и проверки поставки без игрового прогона.
